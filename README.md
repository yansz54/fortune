A fortune written for a houseplant — the kindest, funniest one we could think of.

> "Soon a new leaf will arrive, and your keeper will take credit for it. Let them. You did the growing."

One line, 100 characters, chosen by a 30-candidate pairwise tournament
against the published judge criteria. See `METHOD.md` for the tournament.

Run it with `node main.ts` — it writes the fortune to `/output/entry.txt`.
